How we build

Built by one developer and Claude.

Skyhoard's game code, the script that builds its airship, its build tooling and its tests are all written by Claude Code, working from the command line. The Unity editor has never been opened by hand. The developer designs the game, directs the art and plays the builds.

  1. Direct

    The developer describes the feature, the feel or the fix, and reviews pictures of the result.

  2. Write

    Claude Code writes the C# game code, the scripts that assemble each scene and build the ship, and Python that synthesizes most of the sound effects.

  3. Build

    One command builds the scene, builds the game and runs the tests.

  4. Test

    The game plays itself: a hidden walk-through, two hidden copies playing each other over the network, and benchmark runs.

  5. Play

    A playtest build goes out, and whatever feels wrong goes back to the first step.

The studio

One developer. Claude as the crew.

Sarensong Studios was founded in 2026 by a solo developer. Design, art direction and every final decision come from one desk, and the engineering is done hand in hand with Claude.

Working this way lets one person build a networked 3D game with its own ship pipeline, test suite and benchmarks, work that would normally need a team.
